## 📌 Project Overview
This repository contains an automated API testing suite built with **Karate Framework** and **Java**. The primary objective of this project is to deliver a robust, maintainable, and scalable framework for automated testing of **RESTful APIs** and web services.

It covers critical backend testing capabilities, including HTTP status code assertions, JSON schema validation, payload manipulation, dynamic data handling, and automated execution reports.

---

## 🛠️ Tech Stack & Key Tools
* **Testing Framework:** [Karate Framework](https://github.com/karatelabs/karate) (Behavior-Driven Testing for APIs)
* **Programming Language:** Java JDK 17
* **Build & Dependency Management:** Apache Maven
* **Runner Engine:** JUnit 5
* **Reporting:** Native Karate HTML Reports & Cucumber Reports
